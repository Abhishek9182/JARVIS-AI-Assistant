\# J.A.R.V.I.S. Voice Commands



This document describes the voice-command flow currently implemented in the J.A.R.V.I.S. project.



1\. Voice Pipeline

=================

The current voice pipeline works as follows:



```text

Hey Jarvis

&#x20;   ↓

Wake-word detection

&#x20;   ↓

"Yes sir?"

&#x20;   ↓

Voice recording

&#x20;   ↓

Whisper speech-to-text

&#x20;   ↓

JarvisAgent

&#x20;   ↓

PC Action / Wikipedia / Web Search / Ollama

&#x20;   ↓

JARVIS response

&#x20;   ↓

Text-to-speech











2\. Wake Word

============

The wake phrase is:



Hey Jarvis



J.A.R.V.I.S. waits for the wake word before starting voice-command recognition.



The wake-word detection uses OpenWakeWord.











3\. Wikipedia Commands

=====================

Wikipedia search is triggered when the command starts with one of these phrases:



what is

who is

define

Examples

What is artificial intelligence?

Who is Albert Einstein?

Define machine learning



The recognized search term is sent to Wikipedia and a short summary is returned.











4\. Web Search Commands

======================

Web search is triggered when the command contains one of these keywords:



search

latest

news

weather

Examples

Search for Python jobs

Search for React tutorials

What is the latest news?

What is the weather?



The web-search function uses DuckDuckGo Search.









5\. PC Actions

=============

J.A.R.V.I.S. checks for supported PC actions before performing Wikipedia searches, web searches, or using Ollama.



PC actions are implemented in:



core/actions.py



The exact available actions depend on the implementation in that file.









6\. General AI Commands

======================

If a command does not match a PC action, Wikipedia search, or web-search condition, it is passed to the Ollama-based J.A.R.V.I.S. brain.



The current Ollama model is:



llama3.2:3b

Examples

Hello Jarvis

Explain Python

Tell me a short joke

What can you do?



These requests are handled by the local Ollama model.









7\. Shutdown Commands

====================

The main voice application recognizes these commands for shutting down the voice loop:



shutdown jarvis

exit

quit



Example:



Shutdown Jarvis



J.A.R.V.I.S. responds with:



Goodbye sir.









8\. Voice States

===============

The voice service tracks the following states:



IDLE

LISTENING

THINKING

RESPONDING

ERROR

IDLE



J.A.R.V.I.S. is waiting for the wake word.



LISTENING



The wake word has been detected and J.A.R.V.I.S. is recording the user's command.



THINKING



The command has been received and is being processed by the agent.



RESPONDING



J.A.R.V.I.S. is generating and speaking the response.



ERROR



An error occurred while processing the voice request.











9\. Frontend Voice Visualization

===============================

The React frontend includes a microphone waveform visualization using the browser's Web Audio API.



The browser waveform is a visualization of microphone audio.



The Python voice service separately handles:



OpenWakeWord

Whisper

JarvisAgent

Ollama

Text-to-speech

11\. Command Processing Order

============================

Commands are processed by JarvisAgent in this order:



1\. PC Actions

&#x20;      ↓

2\. Wikipedia

&#x20;      ↓

3\. Web Search

&#x20;      ↓

4\. Ollama



This allows J.A.R.V.I.S. to use available tools before falling back to the local AI model.
